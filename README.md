# RS Trader Sabbir — Link Page + Admin Panel (Shared Database Version)

## এক নজরে
- `index.html` — পাবলিক লিংক পেজ
- `admin.html` — অ্যাডমিন প্যানেল
- `api/data.js` — সার্ভারলেস ফাংশন, Vercel KV ডাটাবেসে ডাটা সেভ/লোড করে
- `package.json` — `@vercel/kv` লাইব্রেরি ডিক্লেয়ার করে

এখন থেকে সব ডাটা (প্রোফাইল, লোগো, লিংক, রিভিউ, ব্যানার) **Vercel KV** নামের একটা ফ্রি ডাটাবেসে সেভ হয় — তাই Admin panel থেকে যেকোনো ডিভাইস/ব্রাউজার থেকে যা পরিবর্তন করবে, **সব ভিজিটর সব জায়গা থেকে (Chrome, Telegram browser, যেকোনো ফোন) একই জিনিস দেখবে।**

## ধাপে ধাপে ডিপ্লয় করার নিয়ম (মনোযোগ দিয়ে করুন, প্রথমবার একটু বেশি ধাপ)

### ধাপ ১: GitHub-এ আপলোড
এই পুরো ফোল্ডারটা একটা GitHub রিপোজিটরিতে পুশ করুন।

### ধাপ ২: Vercel-এ প্রজেক্ট ইম্পোর্ট করুন
1. vercel.com → **Add New → Project**
2. আপনার GitHub রিপো সিলেক্ট করুন
3. Framework Preset: **Other**
4. **Deploy** চাপুন (এই প্রথম ডিপ্লয়ে ডাটাবেস এখনো কানেক্ট করা নেই বলে Admin panel এ লগইন কাজ করবে না — এটা স্বাভাবিক, নিচের ধাপ শেষ করলেই ঠিক হয়ে যাবে)

### ধাপ ৩: Vercel KV ডাটাবেস তৈরি ও কানেক্ট করুন (সবচেয়ে গুরুত্বপূর্ণ ধাপ)
1. ডিপ্লয় হওয়া প্রজেক্টের পেজে যান, উপরে **Storage** ট্যাবে ক্লিক করুন
2. **Create Database** → **KV** (Upstash-powered) সিলেক্ট করুন
3. একটা নাম দিন (যেমন `rsts-db`), রিজিয়ন যেকোনো একটা রাখুন, **Create** চাপুন
4. তৈরি হওয়ার পর ওটা এই প্রজেক্টের সাথে **Connect** করুন (সাধারণত এখানেই "Connect to Project" বাটন থাকে — আপনার প্রজেক্ট সিলেক্ট করে Connect করুন)
5. এতে Vercel অটোমেটিক কিছু Environment Variable (KV_REST_API_URL ইত্যাদি) প্রজেক্টে যোগ করে দেবে — আপনাকে ম্যানুয়ালি কিছু টাইপ করতে হবে না

### ধাপ ৪: রিডিপ্লয় করুন
Storage কানেক্ট করার পর প্রজেক্টের **Deployments** ট্যাবে গিয়ে সর্বশেষ ডিপ্লয়মেন্টের পাশের `...` মেনু থেকে **Redeploy** চাপুন (নতুন Environment Variable যোগ হওয়ার পর একবার রিডিপ্লয় লাগবে)।

### ধাপ ৫: এখন সাইট ব্যবহার করুন
- লাইভ লিংকে গিয়ে `/admin.html` খুলুন
- যেকোনো পাসওয়ার্ড (কমপক্ষে ৪ অক্ষর) দিয়ে প্রথমবার লগইন করুন — এটাই এখন থেকে আপনার অ্যাডমিন পাসওয়ার্ড হয়ে যাবে (মনে রাখবেন!)
- এখন থেকে যা কিছু Admin থেকে সেভ করবেন, সব ডিভাইস/ব্রাউজার থেকে সবাই সেটাই দেখবে

## গুরুত্বপূর্ণ নোট
- **পাসওয়ার্ড ভুলে গেলে**: Vercel ড্যাশবোর্ড → Storage → আপনার KV ডাটাবেস → Data Browser-এ গিয়ে `rsts:admin-secret` key-টা ডিলিট করে দিন। এরপর Admin panel-এ যেকোনো নতুন পাসওয়ার্ড দিয়ে লগইন করলে সেটাই নতুন পাসওয়ার্ড হয়ে যাবে।
- **ছবি সাইজ**: লোগো/রিভিউ স্ক্রিনশট ৩MB পর্যন্ত আপলোড করা যায়, কিন্তু ছোট সাইজের (৫০০KB এর নিচে) ছবি ব্যবহার করাই ভালো — দ্রুত লোড হবে।
- Vercel KV-এর ফ্রি টায়ারই এই সাইটের জন্য যথেষ্ট।

## কাস্টমাইজেশন
- লোগো বদলাতে: Admin → প্রোফাইল ট্যাব → সরাসরি ছবি আপলোড করুন। লোগোর প্রধান রঙ অনুযায়ী সাইটের গোল্ড অ্যাকসেন্ট/গ্লো অটোমেটিক পরিবর্তিত হয়ে ব্লেন্ড করবে।
- ট্রেডিং টিকার (উপরের স্ক্রলিং প্রাইস স্ট্রিপ) `index.html`-এর `.ticker-track` অংশে টেক্সট এডিট করে পরিবর্তন করা যাবে।
- **টপ প্রোমো ব্যানার**: Admin → ব্যানার ট্যাব থেকে অন/অফ, টেক্সট ও লিংক (যেমন Giveaway/Telegram জয়েন লিংক) সেট করা যায়।
- **রিভিউ**: Admin → রিভিউ ট্যাব থেকে যত ইচ্ছা তত রিভিউ যোগ করা যাবে (কোনো লিমিট নেই), সাথে স্ক্রিনশট আপলোডও করা যায়।
- **ডেভলপার সেকশন লকড**: সাইটের নিচের ডেভলপার/ক্রেডিট সেকশন ইচ্ছাকৃতভাবে Admin প্যানেল থেকে এডিট করা যায় না, যাতে ক্লায়েন্ট এটা সরিয়ে ফেলতে না পারে। এটা `app.js` ফাইলের `LOCKED_DEVELOPER` অবজেক্টে হার্ডকোড করা — নিজের নাম/Telegram/Website দিতে হলে সরাসরি কোডে গিয়ে ওই অংশটা এডিট করতে হবে।
